 CUSTOMER TELEPHONE SERVICE STANDARD SCRIPT MANUAL คู่มือมาตรฐานการให้บริการลูกค้าทางโทรศัพท์ ( Call Center) Document Owner: Customer Service Department Document No.: SD-CS-01 Revision: Rev.00 Effective Date: ภายหลังได้รับอนุมัติและประกาศใช้อย่างเป็นทางกา ร บทนำและมาตรฐานมารยาทในการให้บริการทางโทรศัพท์แก่ลูกค้า 1. วัตถุประสงค์ Customer Telephone Service Standard Script Manual จัดทำขึ้นเพื่อกำหนดมาตรฐานการสื่อสารของพนักงาน Customer Service ให้เป็นแนวทางเดียวกันทั้งองค์กร โดยมุ่งเน้นการใช้ถ้อยคำที่สุภาพ เป็นมืออาชีพ เข้าใจง่าย และสร้างประสบการณ์ที่ดีแก่ลูกค้าตลอดการให้บริการทางโทรศัพท์ คู่มือฉบับนี้รวบรวมข้อความมาตรฐาน ( Standard Script) สำหรับสถานการณ์ต่าง ๆ ที่เกิดขึ้นในการให้บริการจริง เพื่อให้พนักงานสามารถเลือกใช้ได้อย่างเหมาะสม ลดความคลาดเคลื่อนในการสื่อสาร และสร้างมาตรฐานการให้บริการเดียวกันในทุกการติดต่อ 2. ขอบเขตการบังคับใช้ คู่มือฉบับนี้ใช้สำหรับ Customer Service Officer Customer Service Supervisor Customer Service Manager พนักงานทุกตำแหน่งที่มีหน้าที่ติดต่อสื่อสารกับลูกค้าทางโทรศัพท์ ครอบคลุมการให้บริการตั้งแต่ การรับสาย การสอบถามข้อมูล การตรวจสอบข้อมูลลูกค้า การประสานงาน การโอนสาย การติดต่อกลับ การรับข้อร้องเรียน การบริหารสถานการณ์ที่มีความเสี่ยง 3. คู่มือฉบับนี้จัดทำในรูปแบบ บทพูดมาตรฐานตามสถานการณ์ แต่ละหัวข้อประกอบด้วย Situation ( สถานการณ์หรือกรณีที่เกิดขึ้นในการให้บริการ ) Customer Objective ( สิ่งที่ลูกค้าต้องการหรือคาดหวังจากการติดต่อ ) Standard Script ( บทสนทนามาตรฐานที่พนักงานควรใช้ ) Alternative Script ( ตัวอย่างบทสนทนาทางเลือกที่สามารถปรับใช้ตามสถานการณ์ ) Recommended Expressions ( ตัวอย่างถ้อยคำที่สุภาพ เป็นมืออาชีพ และสร้างความประทับใจ ) Words to Avoid ( คำพูดที่ควรหลีกเลี่ยง ) พนักงานสามารถเปิดค้นหาตามสถานการณ์และใช้ข้อความมาตรฐานได้ทันที คู่มือมาตรฐานการให้บริการลูกค้าทางโทรศัพท์ ( Customer Telephone Etiquette &amp; Standard Script ) A.1 ➡️ น้ำเสียงและภาษาที่ใช้ในการสื่อสารอย่างมืออาชีพ ■ ใช้สำหรับการสนทนากับลูกค้าทุกประเภท ตั้งแต่เริ่มต้นจนสิ้นสุดการให้บริการ วัตถุประสงค์ของการสื่อสารกับลูกค้า สร้างความประทับใจตั้งแต่เริ่มต้นการสนทนา แสดงความเป็นมืออาชีพ สร้างความเชื่อมั่นให้ลูกค้า ลดความขัดแย้งระหว่างการสนทนา 💬 แนวทางมาตรฐานการสื่อสาร พนักงานควรใช้น้ำเสียง น้ำเสียงที่ควร หลีกเลี่ยง ตัวอย่างถ้อยคำที่แนะนำ สุภาพ ชัดเจน มั่นใจ เป็นมิตร ไม่เร่งรีบ ไม่แสดงอารมณ์ น้ำเสียงห้วน น้ำเสียงประชด การถอนหายใจ การแสดงอารมณ์ไม่พอใจ การพูดเร็วเกินไป " ยินดีให้บริการค่ะ" " ดิฉันขอตรวจสอบข้อมูลเพิ่มเติมนะคะ" " ขออภัยในความไม่สะดวกค่ะ" " ขอบคุณที่รอสายค่ะ" " ขอบคุณที่แจ้งข้อมูลให้ทราบค่ะ" " ดิฉันยินดีช่วยเหลือเต็มที่ค่ะ" คำพูดที่ควรหลีกเลี่ยง คำพูดที่ควรใช้ ไม่รู้ ทำไม่ได้ ไม่ใช่หน้าที่ เป็นความผิดของแผนกอื่น รอก่อน เดี๋ยวค่อยโทรมาใหม่ " ดิฉันขออนุญาตตรวจสอบเพิ่มเติมนะคะ" " ดิฉันขอประสานงานกับหน่วยงานที่เกี่ยวข้องค่ะ" " ดิฉันขอแนะนำแนวทางที่สามารถดำเนินการได้ค่ะ" A.2 ➡️ การกล่าวต้อนรับและทักทายลูกค้า ■ ใช้เมื่อรับสายจากลูกค้าทุกกรณี วัตถุประสงค์ของการสื่อสารกับลูกค้า สร้างความประทับใจตั้งแต่วินาทีแรก แสดงความพร้อมในการให้บริการ ทำให้ลูกค้าทราบว่าติดต่อถูกหน่วยงาน 💬 แนวทางมาตรฐานการสื่อสาร สถานการณ์ แนวทางการสื่อสาร 💬 การสนทนามาตรฐาน เมื่อ กล่าวต้อนรับ หรือ ทักทายลูกค้า " สวัสดีค่ะ บริษัท __________ ดิฉัน __________ จากฝ่าย Customer Service ยินดีให้บริการค่ะ ไม่ทราบว่าวันนี้ให้ดิฉันช่วยดูแลเรื่องใดคะ" 🔄 เมื่อลูกค้าเริ่มอธิบายปัญหาทันที " รับทราบค่ะ ดิฉันยินดีตรวจสอบและช่วยดำเนินการให้ค่ะ รบกวนขอทราบรายละเอียดเพิ่มเติมสักเล็กน้อยนะคะ" 🔄 เมื่อลูกค้าโทรกลับเรื่องเดิม " ยินดีให้บริการอีกครั้งค่ะ ดิฉันขอตรวจสอบข้อมูลของคุณลูกค้าเพิ่มเติมเพื่อดำเนินการต่อให้นะคะ" 🔄 กรณี Complaint " ดิฉันต้องขออภัยในความไม่สะดวกที่เกิดขึ้นนะคะ ดิฉันยินดีรับเรื่องและช่วยตรวจสอบให้ทันทีค่ะ" คำพูดที่แนะนำให้ใช้เสมอ พูดให้ติดปากไว้ ( Recommended Expressions ) ยินดีให้บริการค่ะ รับทราบค่ะ ดิฉันยินดีช่วยตรวจสอบให้ค่ะ ขออนุญาตสอบถามข้อมูลเพิ่มเติมนะคะ A.3 ➡️ การยืนยันตัวตนของลูกค้า ( Customer Verification ) ■ ใช้ ใน ก่อนเปิดเผยข้อมูลลูกค้า หรือดำเนินการเกี่ยวกับข้อมูลในระบบ ตรวจสอบข้อมูลลูกค้า แจ้งข้อมูลการใช้บริการ แก้ไขข้อมูล เปิดเผยข้อมูลส่วนบุคคล ดำเนินการแทนลูกค้า วัตถุประสงค์ของการสื่อสารกับลูกค้า ยืนยันตัวตนของผู้ติดต่อเพื่อความถูกต้องและความปลอดภัยของข้อมูล 💬 แนวทางมาตรฐานการสื่อสาร สถานการณ์ แนวทางการสื่อสาร 💬 การสนทนามาตรฐาน เมื่อต้องการยืนยันตัวตนของลูกค้า 1. " เพื่อความปลอดภัยของข้อมูลคุณลูกค้า ดิฉันขออนุญาตยืนยันข้อมูลก่อนดำเนินการนะคะ" 2. " รบกวนแจ้งชื่อ-นามสกุล หมายเลขทะเบียน หรือข้อมูลที่ใช้ในการลงทะเบียนไว้กับบริษัทค่ะ" 🔄 ข้อมูลไม่ตรง " ขออภัยค่ะ ข้อมูลที่แจ้งมายังไม่ตรงกับข้อมูลในระบบ รบกวนตรวจสอบอีกครั้งได้ไหมคะ" 🔄 ผู้โทรไม่ใช่ผู้มีอำนาจ " เพื่อความปลอดภัยของข้อมูล บริษัทขอสงวนสิทธิ์ในการเปิดเผยข้อมูลเฉพาะผู้มีสิทธิ์เท่านั้นนะคะ" 🔄 กรณีมอบอำนาจ " หากได้รับมอบอำนาจ รบกวนส่งเอกสารตามเงื่อนไขของบริษัทก่อนดำเนินการนะคะ" A.4 ➡️ การรับฟังอย่างตั้งใจและการรวบรวมข้อมูล ( Active Listening &amp; Information Gathering ) เพื่อให้พนักงานสามารถรับฟังความต้องการของลูกค้าได้อย่างครบถ้วน สอบถามข้อมูลเพิ่มเติมอย่างเหมาะสม และรวบรวมข้อมูลที่จำเป็นก่อนดำเนินการหรือประสานงานต่อ ■ ใช้ในกรณีต่อไปนี้ ลูกค้าแจ้งปัญหาหรือข้อร้องเรียน ลูกค้าอธิบายเหตุการณ์ที่เกิดขึ้น ต้องการข้อมูลเพิ่มเติมเพื่อการตรวจสอบ ข้อมูลที่ลูกค้าแจ้งยังไม่ครบถ้วน ต้องทบทวนความเข้าใจให้ตรงกันก่อนดำเนินการ วัตถุประสงค์ของการสื่อสารกับลูกค้า รับฟังลูกค้าอย่างตั้งใจ แสดงความเข้าใจในปัญหาที่ลูกค้าแจ้ง รวบรวมข้อมูลได้ครบถ้วน ลดความคลาดเคลื่อนในการดำเนินงาน สร้างความมั่นใจว่าบริษัทเข้าใจปัญหาของลูกค้าอย่างถูกต้อง 💬 แนวทางมาตรฐานการสื่อสาร สถานการณ์ แนวทางการสื่อสาร 💬 เมื่อลูกค้าเริ่มอธิบายปัญหา รับฟังอย่างตั้งใจและการรวบรวมข้อมูล " รับทราบค่ะ ดิฉันขออนุญาตรับฟังรายละเอียดเพิ่มเติมก่อนนะคะ" 🔄 เมื่อต้องสอบถามข้อมูลเพิ่มเติม " เพื่อให้สามารถตรวจสอบได้อย่างถูกต้อง รบกวนขอรายละเอียดเพิ่มเติมดังนี้ค่ะ..." 🔄 เมื่อต้องการยืนยันความเข้าใจ " ขออนุญาตทวนข้อมูลนะคะ จากที่คุณลูกค้าแจ้ง คือ __________________ ถูกต้องไหมคะ" 🔄 เมื่อลูกค้าแจ้งรายละเอียดหลายประเด็น " ดิฉันขออนุญาตสรุปประเด็นที่ได้รับแจ้งก่อนนะคะ เพื่อให้มั่นใจว่าดิฉันเข้าใจตรงกับคุณลูกค้าค่ะ" 🔄 เมื่อลูกค้าพูดเร็ว " ขออนุญาตสอบถามเพิ่มเติมทีละประเด็นนะคะ เพื่อให้ดิฉันบันทึกข้อมูลได้ครบถ้วนค่ะ" 🔄 เมื่อลูกค้าพูดไม่ชัด " ขออภัยค่ะ รบกวนช่วยกล่าวอีกครั้งได้ไหมคะ เพื่อให้ดิฉันบันทึกข้อมูลได้ถูกต้องค่ะ" 🔄 เมื่อลูกค้าแจ้งข้อมูลไม่ครบ " ขอบคุณสำหรับข้อมูลค่ะ รบกวนขอข้อมูลเพิ่มเติมอีกเล็กน้อยนะคะ เพื่อให้สามารถตรวจสอบได้ครบถ้วนค่ะ" คำพูดที่แนะนำให้ใช้เสมอ พูดให้ติดปากไว้ ( Recommended Expressions ) " รับทราบค่ะ" " ขอบคุณสำหรับข้อมูลค่ะ" " ดิฉันขออนุญาตสอบถามเพิ่มเติมนะคะ" " ขออนุญาตทวนข้อมูลอีกครั้งค่ะ" " เพื่อให้ตรวจสอบได้ถูกต้อง..." คำพูดที่ควรหลีกเลี่ยง " พูดใหม่" " ฟังไม่รู้เรื่อง" " เมื่อกี้พูดอะไรนะ" " เล่าใหม่ทั้งหมด" A.5 ➡️ วิธีปฏิบัติในการพักสาย ลูกค้า ( Hold Procedure ) เพื่อแจ้งให้ลูกค้าทราบว่าจำเป็นต้องใช้เวลาในการตรวจสอบข้อมูลหรือประสานงานเพิ่มเติม พร้อมรักษาประสบการณ์การให้บริการที่ดีระหว่างการรอสาย ■ ใช้ในกรณีต่อไปนี้ ต้องตรวจสอบข้อมูลในระบบ ต้องตรวจสอบข้อมูลจากหลายระบบ ต้องประสานงานกับหน่วยงานที่เกี่ยวข้อง ต้องค้นหาข้อมูลเพิ่มเติมก่อนให้คำตอบ ต้องใช้เวลาในการดำเนินการก่อนตอบลูกค้า วัตถุประสงค์ของการสื่อสารกับลูกค้า แจ้งเหตุผลในการ Hold สาย แจ้งระยะเวลาที่คาดว่าจะใช้ ขออนุญาตก่อน Hold ทุกครั้ง ทำให้ลูกค้าทราบว่าจะได้รับการดูแลต่อเนื่อง 💬 แนวทางมาตรฐานการสื่อสาร สถานการณ์ แนวทางการสื่อสาร 💬 การสนทนามาตรฐาน เมื่อต้อง การพักสาย ลูกค้า " รบกวนขออนุญาตตรวจสอบข้อมูลเพิ่มเติมสักครู่นะคะ ใช้เวลาประมาณ ______ นาทีค่ะ ขออนุญาต Hold สายไว้สักครู่นะคะ" 🔄 กรณีต้องตรวจสอบหลายระบบ " เนื่องจากต้องตรวจสอบข้อมูลเพิ่มเติมจากระบบค่ะ รบกวนขออนุญาต Hold สายประมาณ ______ นาที ระหว่างนี้ดิฉันจะเร่งดำเนินการให้เร็วที่สุดค่ะ" 🔄 กรณีต้องประสานงานกับหน่วยงานภายใน " ดิฉันขออนุญาตประสานงานกับหน่วยงานที่เกี่ยวข้องเพิ่มเติมนะคะ รบกวนถือสายรอประมาณ ______ นาทีค่ะ" 🔄 กรณีต้องใช้เวลามากกว่าปกติ " ขออนุญาตใช้เวลาตรวจสอบเพิ่มเติมอีกเล็กน้อยนะคะ ดิฉันจะกลับมาแจ้งความคืบหน้าให้คุณลูกค้าทราบโดยเร็วที่สุดค่ะ" คำพูดที่แนะนำให้ใช้เสมอ พูดให้ติดปากไว้ ( Recommended Expressions ) " ขออนุญาต" " รบกวนถือสาย" " ใช้เวลาประมาณ..." " ดิฉันจะกลับมาแจ้งความคืบหน้า" คำพูดที่ควรหลีกเลี่ยง " รอก่อน" " เดี๋ยว" " ถือสาย" " แป๊บ" A.6 ➡️ การแจ้งความคืบหน้าระหว่างการพักสายเป็นเวลานาน ถ้าว่างจะโทร" " ไม่รู้เมื่อไร" 💡 เคล็ดลับการให้บริการ ( Service Tips) ยืนยันหมายเลขทุกครั้ง ระบุเวลาให้ชัดเจน อย่าสัญญาเวลาที่ไม่สามารถทำได้ A.13 ➡️ การยืนยันการนัดหมายเพื่อติดต่อกลับ Standard หลักการสื่อสารเชิงบวก ( Positive Communication) การเลือกใช้ถ้อยคำเชิงบวกสามารถช่วยลดความตึงเครียดของการสนทนา เพิ่มความเชื่อมั่นของลูกค้า และสร้างประสบการณ์ที่ดี แม้ในสถานการณ์ที่ไม่สามารถตอบสนองความต้องการของลูกค้าได้ทั้งหมด แทนที่จะพูด แนะนำให้ใช้ ทำไม่ได้ ดิฉันขอแนะนำแนวทางที่สามารถดำเนินการได้ค่ะ ไม่รู้ ดิฉันขออนุญาตตรวจสอบเพิ่มเติมนะคะ ไม่มีข้อมูล ขณะนี้ยังไม่พบข้อมูลที่สามารถยืนยันได้ค่ะ รอก่อน รบกวนถือสายสักครู่นะคะ เดี๋ยว ใช้เวลาประมาณ ______ นาทีค่ะ ผิด อาจมีความคลาดเคลื่อนของข้อมูลค่ะ ระบบเสีย ขณะนี้ระบบอยู่ระหว่างการตรวจสอบค่ะ ไม่ใช่หน้าที่ ดิฉันจะประสานผู้รับผิดชอบให้ค่ะ ไม่ได้ ขออนุญาตตรวจสอบเงื่อนไขเพิ่มเติมนะคะ โทรใหม่ ดิฉันขอติดต่อกลับให้ค่ะ คลังประโยคเชิงบวกสำหรับการให้บริการลูกค้า ( Positive Sentence Library ) ใช้บ่อยระหว่างการสนทนา ดิฉันยินดีให้บริการค่ะ ขอขอบคุณที่แจ้งข้อมูลให้ทราบค่ะ ขออภัยในความไม่สะดวกที่เกิดขึ้นค่ะ ดิฉันเข้าใจความรู้สึกของคุณลูกค้าค่ะ ดิฉันจะช่วยติดตามเรื่องนี้ให้ค่ะ ขออนุญาตตรวจสอบเพิ่มเติมนะคะ ดิฉันจะรีบดำเนินการให้ค่ะ ขอขอบคุณที่กรุณารอสายค่ะ ขออนุญาตสรุปข้อมูลอีกครั้งนะคะ หากมีข้อสงสัยเพิ่มเติม สามารถติดต่อเราได้ทุกเมื่อค่ะ ถ้อยคำที่แนะนำให้ใช้ การกล่าวต้อนรับและทักทาย ( Greeting ) สวัสดีค่ะ ยินดีให้บริการค่ะ ดิฉัน __________ จากฝ่าย Customer Service ค่ะ ไม่ทราบว่าวันนี้ให้ดิฉันช่วยดูแลเรื่องใดคะ การตรวจสอบความถูกต้อง ของข้อมูล ( Verification ) เพื่อความปลอดภัยของข้อมูล ขออนุญาตยืนยันข้อมูลก่อนนะคะ รบกวนแจ้ง... ขออนุญาตตรวจสอบข้อมูลค่ะ การรับฟังอย่างตั้งใจ ( Active Listening ) รับทราบค่ะ ขอบคุณสำหรับข้อมูลค่ะ ขออนุญาตสอบถามเพิ่มเติมนะคะ ขออนุญาตทวนข้อมูลอีกครั้งค่ะ การ ขออนุญาตพักสายลูกค้า ( Hold ) รบกวนถือสายสักครู่นะคะ ใช้เวลาประมาณ... ขออนุญาต Hold สายค่ะ ขอบคุณที่กรุณารอสายค่ะ การโอนสาย ( Transfer ) ขออนุญาตโอนสายค่ะ ดิฉันจะประสานงานให้ค่ะ ไม่ต้องอธิบายข้อมูลซ้ำค่ะ การขอติดต่อกลับ ( Callback ) ดิฉันจะติดต่อกลับภายใน... ขออนุญาตนัดหมายเวลาติดต่อกลับค่ะ จะติดตามเรื่องให้จนแล้วเสร็จค่ะ ลูกค้าร้องเรียน / ไม่พึงพอใจ ( Complaint ) ขออภัยในความไม่สะดวกค่ะ ดิฉันเข้าใจความรู้สึกของคุณลูกค้าค่ะ ดิฉันจะเร่งดำเนินการให้ค่ะ จบการสนทนา ( Closing ) มีเรื่องอื่นให้ดิฉันช่วยเหลือเพิ่มเติมไหมคะ ขอบพระคุณที่ใช้บริการค่ะ ขอให้มีความสุขในวันนี้ค่ะ คำต้องห้ามในการสื่อสารกับลูกค้า คำที่ไม่ควรใช้ เหตุผล ไม่รู้ แสดงถึงการไม่รับผิดชอบ ทำไม่ได้ เป็นการปฏิเสธทันที ผิด ทำให้ลูกค้ารู้สึกถูกตำหนิ รอก่อน ไม่มีกรอบเวลา เดี๋ยว ไม่ชัดเจน โทรใหม่ ผลักภาระให้ลูกค้า ระบบพัง ส่งผลต่อภาพลักษณ์ ไม่ใช่หน้าที่ ขาดความรับผิดชอบ ใจเย็น ๆ กระตุ้นอารมณ์ลูกค้า บริษัทไม่ผิด สร้างความขัดแย้ง คำที่ควรหลีกเลี่ยงเมื่อรับ Complaint ก็แจ้งแล้ว เป็นกฎ ไม่มีทาง ทำอะไรไม่ได้ แผนกอื่นผิด เชิญฟ้อง โพสต์ได้เลย แล้วแต่ลูกค้า หลักการสื่อสารกับลูกค้า 10 Golden Rules ยิ้มก่อนรับสายเสมอ รับฟังให้มากกว่าพูด อย่าพูดแทรกลูกค้า ใช้ภาษาที่เข้าใจง่าย อย่าคาดเดาข้อมูล อย่ารับปากในสิ่งที่ไม่มีอำนาจ กล่าวขอบคุณทุกครั้ง กล่าวขออภัยเมื่อเกิดผลกระทบ เน้นการแก้ไขปัญหา ไม่เน้นการโต้แย้ง จบการสนทนาด้วยความประทับใจ
