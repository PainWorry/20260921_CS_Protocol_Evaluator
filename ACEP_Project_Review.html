2. แผนการดำเนินงานและสถานะปัจจุบัน (Milestone Review)

ภาพรวมของการส่งมอบงานตามแผนที่วางไว้ เพื่อใช้ปรึกษาหารือและกำหนดทิศทางขั้นต่อไป

  • [เสร็จสิ้น] ระยะที่ 1: ระบบฐานข้อมูล (Persistent Data Layer)
    • ออกแบบ Database Schema เชิงสัมพันธ์รองรับ PDCA ด้วย SQLAlchemy
    • ระบบสามารถสลับจาก SQLite ไปใช้ PostgreSQL ได้ทันทีเมื่อขึ้น Production
  • [เสร็จสิ้น] ระยะที่ 4: หน้าจอแดชบอร์ด (QA Manager & Agent UI)
    • พัฒนาหน้าจอ Streamlit สำหรับพนักงาน (ประเมินตนเองผ่าน Text/Audio/Docs)
    • พัฒนาหน้าจอ Inbox สำหรับหัวหน้า QA แบบ Side-by-side view
  • [กำลังดำเนินการ] ระยะที่ 2: ระบบเซ็นเซอร์ข้อมูลส่วนบุคคล (PII Redaction)
    • ประเด็นหารือ: การพัฒนา Middleware สำหรับเซ็นเซอร์ข้อมูลลูกค้า (ชื่อ, เบอร์โทร) ก่อนส่งให้ Public AI เพื่อความปลอดภัยด้าน PDPA
  • [แผนในอนาคต] ระยะที่ 3: ระบบจำลองลูกค้าด้วยเสียง (Voice Simulator)
    • ประเด็นหารือ: การเชื่อมต่อ WebRTC กับ Gemini Multimodal Live API เพื่อให้พนักงานซ้อมคุยโต้ตอบด้วยเสียงแบบ Real-time โดยไม่ต้องเสียค่าโทรศัพท์ (Twilio)
